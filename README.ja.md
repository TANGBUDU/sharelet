# Sharelet 0.5.2

Hermes でいつも使っているツールを、ワンクリックで誰でも開けるリンクにします。ゲストに必要なのはブラウザだけで、エージェントもアカウントもキーも要りません。再接続後も同じアドレスを使うには、自分の中継サーバーまたは固定の公開アドレスを設定します。

## 3ステップで始める

1. プラグインを Hermes プロファイルの `plugins` フォルダーに展開して有効にします。

   ```yaml
   plugins:
     enabled: [sharelet]
     entries:
       sharelet:
         mcp_allowlist: [my_tools]   # すでに使っていて信頼できる MCP サーバー
         settings:
           enabled: true
   ```

2. Hermes を起動して `sharelet_status` を実行し、表示された作成者ページを開きます。
3. ツールを選んで **共有リンクを作成** を押し、リンクをコピーして送ります。

リンクは初期設定で 20 回・7 日間使え、いつでも閉じられます。**詳細設定** では回数（最大 1,000）と有効期限（最大 30 日）の変更、名前の変更、ゲストに変えさせたくない入力の固定ができます。データの変更、メッセージ送信、料金の発生を伴うツールは作成前に一度だけ確認します。破壊的と指定されたツールは共有できません。

ツールはあなたのパソコンで動くため、起動中だけリンクが使えます。自分で運営する任意の中継サーバーを使うと、オフライン表示と復帰待ちが可能です。

## 公開アドレスと任意の固定リンク

公開リンクがある間、Sharelet はゲスト専用の Cloudflare 一時アドレスを自動で開き、切れれば再接続します。**中継は既定で無効で、中継サーバーへは接続しません。** アドレスが変わった場合はリンクをコピーし直します。固定リンクには、自分の中継サーバーを `relay_url` に設定するか、固定の `public_origin` を用意してください。

```
https://relay.example.com/h/<ホストID>#<リンクのトークン>
```

明示的に有効にすると、中継サーバーはランダムなホスト ID、中継用シークレット、現在の一時アドレスを受け取ります。トークンは `#` 以降にあり、API への HTTP リクエストには含まれません。ただし中継ページの JavaScript はトークンを処理するため、サーバーと配信コードを自分で管理してください。

プラグインの `settings` で変更できます。

| 設定 | 効果 |
|---|---|
| （既定） | 中継なし。一時アドレスを使い、登録もハートビートも送信しません。 |
| `relay_url: https://relay.example.com` | 自分の中継サーバーを明示的に使用します。サーバーコードは `relay_service/` にあります。 |
| `relay_url: ""` | 中継サーバーを使いません。リンクは一時アドレスを直接使い、再接続後に変わります。 |
| `public_origin: https://my-pc.example.ts.net` | 自分で用意した固定アドレスをゲスト用ポートに向けます（例：`tailscale funnel 9272`、Cloudflare の名前付きトンネル）。一時トンネルも中継サーバーも使いません。 |

どの方法でも、リンクを使うにはパソコンが起動している必要があります。Sharelet がツールを別の場所でホストすることはありません。

0.5.1 から更新した場合は Hermes を再起動してください。従来の作者運営の中継は自動では使いません。新しい直接リンクをコピーするか、自分で運営する中継を明示的に設定してください。署名キー、利用回数、有効期限は元のワークスペースに残ります。

自動導入する cloudflared は 2026.10.7 に固定し、コード内の SHA-256 と起動前のキャッシュ検証を使います。Linux AMD64/ARM64 は各ネイティブ版、Windows AMD64 は公式 x64 版です。Windows ARM64 の公式ネイティブ版はないため、Windows 11 ARM64 では同じ公式 x64 版を OS のエミュレーションで使います。この選択とチェックサムはテスト済みですが、ARM64 実機では未検証です。

## 詳細

以下はすべて任意です。

### 実際のプラグインを共有する例

カタログ掲載済みの [Weather 2.1.0](https://github.com/FahrenheitResearch/hermes-weather-plugin/tree/d474493ef4ffeefabad9dbf0188f72bce3b47b67) を変更せず Hermes に読み込み、Sharelet から公開 `ctx.dispatch_tool` 経由で元の `wx_global` を呼び出しました。ブラウザーで都市を選ぶと実際の天気データを取得できます。元の関数の呼び出し記録とソースハッシュを照合済みです。MCP サーバー、モデル、有料キーは使いません。検証範囲は世界の現在の天気のみで、レーダー・数値計算機能は未検証です。

[PDF ワークショップ](examples/pdf_workshop/README.md) は独立した MCP ファイルアダプターの例です。PDF の結合、抽出・並べ替え、圧縮とダウンロードに対応します。既存の Hermes ネイティブプラグイン接続の検証ではありません。

オプションの [Permission Canvas 体験室](examples/permission_canvas/README.md) は、インストール済みの Permission Canvas バックエンドを限定的な MCP ツールとして提供します。架空の作業画面で、編集可能、読み取り専用、承認待ち、非表示の項目を試せます。権限判断と画像・テキストのマスクは元のプラグインが実行します。実際のデスクトップやモデルには接続しません。Sharelet はマスク済み画像と実行結果を表示します。これは確認済みのアダプターの例であり、デスクトップ全体を自動公開する機能ではありません。

いつものツールを、誰でも使えるリンクに。

共有するツールを選び、重要な設定を固定して、利用回数と有効期限を決めます。利用者はブラウザーでリンクを開き、入力して結果を受け取れます。エージェントのインストールやAPIキーの入力は不要です。

画面は初回に英語で表示されます。言語メニューから **English / 简体中文 / 日本語** を選べます。選択はブラウザーに保存されます。内蔵ツールの名前、説明、入力項目、ボタン、ダイアログ、エラーを各言語で表示します。独自に入力した文章や外部ツールの出力は保持します。言語切り替えにモデルや翻訳APIは使いません。

### ローカルで試す

Python 3.11以降を推奨します。

```bash
python app.py --mode local
```

`.state/owner-entry.txt` にある非公開のURLを開いてください。内蔵の **Text cleanup（テキスト整形）** と **Reading time（読了時間）** は、モデルや有料APIを使わずにローカルで動作します。

「詳細設定」で「このパソコンだけで使う」を選ぶとローカルのプレビューを作成できます。公開リンクでは利用者専用の公開アドレスを自動で開きます。`--relay-url ""` で中継サーバーを使わず、`--public-origin https://...` で自分のアドレスを使えます。

Windowsでは `Start-Sharelet.ps1` から起動できます。

### 既存の接続を使う

- **Hermes：** プラグインを対象プロファイルの `plugins/sharelet/` に配置し、有効にします。共有を許可するMCPサーバーを `mcp_allowlist` に指定します。`sharelet_status` は非公開の入口ファイルの場所を返します。
- **単体モード：** `requirements-preview.txt` をインストールします。「接続設定」で既存のMCP設定ファイルを指定し、接続するサーバーを選びます。認証情報は元のファイルを使います。
- **ほかのエージェント：** `sharelet_mcp.py` をstdio MCPサーバーとして登録します。エージェントが作成するのは下書きだけです。オーナーがワークスペースで確認して承認すると、リンクが有効になります。

詳細な設定例は [English README](README.md)、検証内容は [VALIDATION.md](VALIDATION.md) を参照してください。

### 画像生成は任意

粘土、アニメポートレート、ステッカーのレシピを用意しています。画像アダプターを設定したときだけ、作成者ページに画像の設定が表示されます。ワークスペース専用のキーを入力するか、現在の Hermes プロファイルのキーを明示的に有効にします。`OPENAI_API_KEY` は `agent.secret_scope.get_secret` で解決し、バックグラウンド処理でもプロファイルの範囲を維持します。スコープが利用できない場合、プロセス環境のキーへはフォールバックしません。

リンク作成や言語切り替えでモデル料金は発生しません。ツールを実行すると、共有者が接続したサービスの利用料金が発生する場合があります。配布物に開発者のキーや実行用アカウントは含まれていません。

### 利用範囲と承認

リンクの回数は、それを持つ全員で共有します。リンクごとの回数とは別に、ワークスペース全体の累計の安全上限があり、既定は総実行10,000回、画像生成30回です（`execution_limit` と `generation_limit` で設定）。回数は再起動後も保持されます。試行回数の上限であり、金額の上限ではありません。失敗や中断も回数に含まれる場合があります。

待機中のリクエストは、ツールを呼び出す直前にリンクの状態とツールの承認を再確認します。未送信と確認できたリクエストの利用回数は返還します。すでに外部ツールへ送信した処理は、リンクを無効にしても取り消せません。JSON の受信枠はリスナーごとに8件、リンクごとに2件で、受信期限は10秒です。

明確に破壊的と指定されたツールは共有できません。読み取り専用か不明なツールや書き込みを行うツールには、共有ごとの追加確認が必要です。読み取り専用のツールでも、出力に非公開の情報が含まれていないか確認してください。

公開するのは利用者向けのサービスだけです。オーナーとエージェントの管理APIは公開しません。この区別はプラグインのAPIに適用されます。同じOSアカウントで任意のファイル操作やコマンド実行を別途許可したエージェントを、OSレベルで隔離するものではありません。
