# Sharelet 0.5.2

把你在 Hermes 里已经在用的一个工具，点一下就变成别人打开就能用的网页链接。访客只需要浏览器，不用装 Agent、不用注册、不用填密钥。需要重连后地址保持不变时，可以配置自己的跳转站或固定公网地址。

## 三步上手

1. 把插件解压到 Hermes 配置的 `plugins` 目录并启用：

   ```yaml
   plugins:
     enabled: [sharelet]
     entries:
       sharelet:
         mcp_allowlist: [my_tools]   # 你已经在用、信得过的 MCP 服务器
         settings:
           enabled: true
   ```

2. 启动 Hermes，让它运行 `sharelet_status`，打开它给出的创作者页面。
3. 选一个工具，点 **生成分享链接**，复制后发给别人。

每条链接默认可用 20 次、有效 7 天，随时可以关闭。展开 **更多设置** 可以改次数（最多 1000）和有效期（最多 30 天）、改名，或者固定访客不该改的输入。可能修改数据、发消息或产生费用的工具，生成前要你确认一次；标为破坏性的工具不能分享。

工具在你的电脑上运行，电脑需要保持在线。可选的自建跳转站能在电脑关机时显示“创作者暂时离线”，并等待重新上线。

## 公网地址与可选的固定链接

有公开链接时，Sharelet 会自动为访客开一个 Cloudflare 临时地址，断了会自动重连。**默认不使用或联系任何跳转站**，临时地址变化后需要重新复制链接。需要固定链接时，请运行自己的跳转站并设置 `relay_url`，或使用自己的 `public_origin`：

```
https://relay.example.com/h/<你的主机号>#<链接凭证>
```

明确启用后，跳转站会接收主机的随机编号、中继密钥和当前临时地址。链接凭证放在 `#` 后面，不会出现在发往跳转站 API 的 HTTP 请求里；但跳转页面的 JavaScript 会处理这段内容，因此跳转站应由你自己运营，并控制它提供的代码。

可以在插件的 `settings` 里调整：

| 设置 | 效果 |
|---|---|
| （默认） | 不用跳转站，直接使用临时地址，不发送中继注册或心跳。 |
| `relay_url: https://relay.example.com` | 明确启用你自己的跳转站，服务端代码在 `relay_service/`。 |
| `relay_url: ""` | 不用跳转站，链接直接用临时地址，重连后会变。 |
| `public_origin: https://my-pc.example.ts.net` | 用你自己维护的固定地址指向访客端口（例如 `tailscale funnel 9272` 或 Cloudflare 命名隧道），不再开临时隧道，也不用跳转站。 |

无论哪种方式，电脑都要开着链接才能用；Sharelet 不会把你的工具托管到别处。

从 0.5.1 升级后请重启 Hermes。旧版自动使用的作者跳转站不再启用，需要复制新的直连链接，或明确配置自己运营的跳转站。链接签名密钥、使用次数和有效期仍保存在原工作台中。

## 进阶

以下内容都是可选的。

### 真实插件分享示例

已用官方目录收录的 [Weather 2.1.0](https://github.com/FahrenheitResearch/hermes-weather-plugin/tree/d474493ef4ffeefabad9dbf0188f72bce3b47b67) 完成原生插件验证：Hermes 正式加载未修改的原插件，Sharelet 通过公开 `ctx.dispatch_tool` 调用其 `wx_global`，访客在网页选城市后获得实际天气数据。调用记录核对到了原插件的函数和源码哈希。配置中没有 MCP 服务器，也不需要模型或付费密钥。本次仅验证全球天气工具，其他雷达和计算功能未测。

[PDF 工作台](examples/pdf_workshop/README.md) 是独立的 MCP 文件适配示例，可以处理访客自己的文件：合并、提取、调序、压缩并下载。它调用本地 pypdf 工具，不属于现成 Hermes 原生插件的接入验证。

可选的 [Permission Canvas 体验台](examples/permission_canvas/README.md) 把已安装的 Permission Canvas 后端接成一个范围受限的 MCP 工具。访客可以在虚拟工作台里试绿区编辑、蓝区只读、黄区审批和黑区隐藏。权限判断、截图遮挡和文本隐藏都由原插件实际执行；不连接真实桌面，也不调用模型。Sharelet 展示实际返回的遮挡截图和执行结果。这是经过审查的适配器示例，不是自动把整个桌面插件发布到公网。

### 先试免费工具

建议 Python 3.11 以上。在本目录运行：

```bash
python app.py --mode local
```

打开 `.state/owner-entry.txt` 中的私人工作台地址，选择 **Text cleanup（文字整理）** 或 **Reading time（阅读时间）**。这两个工具在本机计算，不调用模型，也不用 API Key。首次打开默认英文，可从语言菜单选择 **English / 简体中文 / 日本語**，浏览器会记住选择。内置工具的名称、说明、表单字段、选项、弹窗和错误提示一同切换。切换不调用模型或翻译 API，输入内容和正在运行的请求会保留。

创建分享时，可以在“更多设置”里把大小写、阅读速度等参数固定，让访客只填写剩下的字段。勾选“只在本机使用”即可先做本地预览；公开链接会自动建立只通向访客端口的公网连接。默认关闭跳转站；用 `--relay-url https://relay.example.com` 可明确启用自建跳转站，用 `--public-origin https://...` 可使用你自己的固定地址。

自动下载的 cloudflared 固定为 2026.10.7，使用代码内的 SHA-256 校验，并在启动前重新校验缓存。Linux AMD64/ARM64 使用各自原生包；官方没有 Windows ARM64 原生包，Windows 11 ARM64 明确使用官方 AMD64 包，经系统 x64 仿真运行，校验值相同。该兼容路径完成了选择和校验测试，未做 ARM64 实机验证。

Windows 可以运行 `Start-Sharelet.ps1`。已有开发预览时直接打开，否则启动独立工作台。

### 复用已有工具

- **Hermes 插件模式：** 放进对应配置的 `plugins/sharelet/`，启用插件，并在 `mcp_allowlist` 中明确列出允许分享的服务器。调用 `sharelet_status` 获取私人入口文件的位置。使用 Hermes 的公开接口发现和执行工具。
- **独立模式：** 安装 `requirements-preview.txt`。在“连接”里选择本机已有的 MCP 配置文件，读取服务器列表，再明确勾选要连接的服务器。程序只保存文件引用和所选名字，不另抄一份密钥。支持 stdio 和 Streamable HTTP。
- **其他 Agent：** 将 `sharelet_mcp.py` 配置为 stdio MCP 服务器，可以查询工具、准备分享草稿、查看和关闭自己经批准的分享。Agent 不能自行批准：你需要打开私人工作台，检查工具、参数、次数和访问范围后确认。草稿一小时后失效，链接有效期从批准时开始计算。它只使用工作台已接入的工具，不会自动取得宿主 Agent 的全部能力。

完整配置示例在 [英文 README](README.md)。实际测过的客户端版本与审批限制在 [验证记录](VALIDATION.md)。

### 出图是可选项

提供黏土角色、动漫头像、贴纸三套预设。只有配好出图适配器后，创作者页面才会出现出图相关设置。只有选择这些功能时才需要分享者连接自己的 OpenAI 出图服务，也可以引用服务器上已经存在的密钥文件。模型、尺寸、张数和主人设置的风格固定，访客只填写角色描述。

别人安装 Sharelet 后，使用的是他们自己的服务和账号，不会计费到开发者账号。出图功能之外，普通工具仍然可以独立使用。

当前 Hermes profile 的 `OPENAI_API_KEY` 需要主人明确启用后才用于出图，通过 `agent.secret_scope.get_secret` 获取，并在后台线程中保留该 profile 的范围。没有可用的 Hermes 密钥作用域时，可以在 Sharelet 内填写该工作台自己的密钥。

### 当前支持范围

最多八个简单输入字段，支持文字、数字、整数、布尔值和枚举，结果为有限长度的文字/JSON；支持的图片预设可以直接展示和下载 PNG。经过审查的文件适配器可通过 `format: sharelet-pdf-uploads` 接收受分享链接约束的 PDF 上传，并返回可下载的 PDF。暂不支持通用嵌套对象、数组、任意主机路径、远程媒体和 OAuth 登录。不能分享的工具会显示原因。

每条链接的次数由所有持有者共用，不是每个人各有一份。在每条链接的次数之外，工作台还有一个累计安全上限：默认 10,000 次工具运行，其中出图最多 30 次，可用 `execution_limit` 和 `generation_limit` 配置；这些是持久保存的尝试次数，不是每日额度或金额预算，已用次数不会清零。已受理的失败或中断也可能计次。刷新会找回原请求，不会自动重新执行。

排队请求在真正调用工具前会重新检查链接状态和工具授权。确定尚未发送到工具的请求会退还次数；已经发送到远端的操作无法通过撤销链接取消。JSON 接收使用独立的 8 个名额，每条链接最多占 2 个，且必须在 10 秒内传完，避免慢请求占满访客连接。

无效输入不会占用执行限流额度，慢任务有界排队；Hermes 调用超过 180 秒仍未返回时，会标记结果不确定并停止等待，远端可能仍在完成，系统不会自动重试。

主人端与访客端分开，公网只暴露访客端。接口会重新检查工具授权和输入规则，固定参数不能被访客覆盖。结果保存在分享者的主机上，关闭或过期后清理；已经下载的结果无法收回。分享前仍需要审查工具输出，避免把私有资料通过只读工具公开出去。

明确标为破坏性的工具禁止分享；没有只读声明或可能写入的工具，每条分享都需要主人额外确认准确的工具与设置。主人和 Agent 使用独立凭证，Agent 传一个同意字段不能绕过审批。这是插件接口的权限隔离；如果你另外给 Agent 同账号下任意读文件或执行命令的权限，它仍可能在插件外访问私有文件。

从 0.4 升级后，请重启服务和 MCP 连接，重新打开 `owner-entry.txt` 中的私人入口。新版主人凭证使用 `owner-v2.key`，不再接受旧的 `owner.key`；旧版未经过新审查的未知或写入工具分享需要重新创建并批准。

公网临时地址由 Cloudflare 临时隧道提供：有公开链接时自动开启，没有时自动关闭，断开后按退避间隔自动重连。用跳转站时链接在重连和重启后保持不变；不用跳转站时重连后需要重新复制链接。次数和关闭状态会保留。这不是永久托管，也不保证在线时长。

测试、真实出图和持续运行证据见 [VALIDATION.md](VALIDATION.md)。
