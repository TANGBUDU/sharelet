A LITTLE GUIDE

Three steps to share a tool.

1
Pick a tool

Any tool you have authorised in Hermes shows up here.

2
Create the link

It allows 20 runs for 7 days by default. Change that, or fix some inputs, under More settings.

3
Send it

Guests use the tool in their browser. Close the link any time to stop it.

The tool runs on your computer, so links work while it is on. The link itself never changes, even after a restart.
